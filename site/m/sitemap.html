Scope

Every design unit maps to real paths under ohao/ and shaders/. Non-product research trees are omitted from the public face. Each leaf documents what, how, and why.

01 · Architecture

  • Hub — architecture.html
  • Request path — CLI/example → Scene → VulkanRenderer::initialize → setScene → render → pixels.
  • Cross-module invariants — Contracts that break pixels silently if violated.
  • Module ownership map — Which directory owns which concern; forbidden dependencies.

01b · Core

  • Hub
  • Types & concepts — GpuPod, common_types, C++20 concepts used across modules.
  • EventBus — Thread-safe pub/sub with typed subscribe helpers.
  • Command history & Result — Undo/redo command pattern and fallible Result type.
  • Logger — OHAO_LOG: levels, channels, a 4,096-record ring and sinks; every engine message.

02 · Scene

  • Hub — scene.html
  • ECS world & hierarchy — EnTT registry, ordered systems, Parent/Children with cycle rejection, subtree destroy.
  • Transform propagation — Parent-first world matrices, prevWorld motion history, the patch rule and verifyTransforms.
  • Render extract — Registry to RenderScene: slots in creation order, dirty uploads, lights, stale mesh handles.
  • RenderScene — Mesh arenas with one BLAS per mesh, material/instance/light tables, per-slot staging, retire queue, TLAS build vs refit.
  • Animation: saved integers, a pose per frame, a mesh per instance — Animators save steps, not time; drivers read saved state; a skinned instance is its own deformed mesh.
  • Asset loaders — Assimp (GLB/GLTF, node transforms applied), ufbx + Assimp (FBX), native OBJ, procedural primitives.

12 · Reflection & agent API

  • Hub
  • Type registry & schema — Registered types with docs, units and limits; the lint; the catalogue, the scene JSON Schema and schemaHash.
  • Canonical scene files — Stable entity ids, defaults omitted, the one pretty layout, per-type writers and shortest floats.
  • Loading & validation — Two-phase load, the streaming fast path and the tree decoder, structured diagnostics, versions and upgrades.
  • Snapshots & restore — Columnar captures of every saved component, and a restore that writes only what differs.
  • Session, commands & queries — The method table, atomic command batches with inverses and rollback, $k references, queries and summaries.
  • Instantiate & the scene view — MeshSource to MeshRenderer through a backend seam, shared meshes, the asset resolver, Camera and Environment.
  • The ohao CLI & render host — One JSON document on stdout, exit classes, scripts as RPC requests, render.capture through a host.

13 · Agent control surface

  • Hub
  • The protocol server — JSON-RPC 2.0 and MCP on one server: a reader thread and an engine thread, cancellation, progress, the error table, tools from params structs, a bounded queue.
  • Transports: stdio and the named pipe — Newline framing without holding oversize lines, stdout kept for the protocol, interruptible reads, and a pipe only the current user on this machine can open.
  • The live host — One window loop for ohao_game and ohao serve --window: requests at a fixed point of the frame, render on change, replies after present.
  • Time and input as data — Lockstep and realtime on one step axis, an input map stepped per simulation step, injection, and recordings that check themselves.
  • Frame capture — One capture procedure for both hosts, readback on request, previews made on the GPU or beside the result, and a fast lossless PNG writer.
  • World hash, diff and determinism — A 64-bit fingerprint of the authoring state, changed fields against a snapshot, and bit-identical lockstep worlds and deferred captures.

14 · Runtime feel

  • Hub
  • Feel: the look lead, frame timing and the first-person gun — The look no step has taken drawn through the step's own arithmetic, present-confirmed latency and pacing, a view-space gun that never shadows, and sparks and sounds from the combat log.

05 · Deferred

  • Hub — deferred.html
  • DeferredRenderer orchestrator — Pass ownership, resize, setScene, graph execute.

  • Deferred lighting — The froxel's light loop through OpenPBR's base, split-sum IBL, SSAO, shadows.

  • Post stack — Bloom, TAA, tonemap orchestration.
  • Gizmo pass — Debug/editor overlay meshes.

06 · Path tracer

  • Hub — path-tracer.html
  • Host lifecycle — ensureRTRenderer, images, pipeline, SBT, descriptors.
  • Profiles & meta — RTRenderSettings, Realtime vs Offline traits.
  • Acceleration structures — BLAS/TLAS API, rebuild vs update.
  • Raygen integrator — The OpenPBR path tracer: NEE + BSDF sampling under MIS, AOV writes.
  • Radiance cache — A world-space hash grid of reflected radiance, filled by a sparse update trace and read by realtime paths past their first vertex: SHaRC's design in OHAO's Slang.
  • Hit & miss shaders — closesthit materials, anyhit alpha, miss env.
  • Descriptor map 0–41 — Set-0 layout: TLAS, images, AOVs and guides, scene tables, OpenPBR tables, the radiance cache.
