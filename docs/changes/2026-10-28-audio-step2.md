# Sub-project 11, step 2: reverb zones and occlusion

**Spec:** `docs/specs/2026-10-28-audio-design.md` ("The step: the schedule" (occlusion, reverb
zones), "Components and hints", "Performance budgets", "As built (step 2)"); plan
`docs/plans/2026-10-28-audio.md`, Task 2.
**Status:** built (step 2 of 4). The game still plays through the category API, so it sounds as
before. The schedule now runs in every world with audio installed and writes zone and occlusion
commands, which nothing plays yet. Row 11 stays open.

## 1. Summary

- **A reverb on the return bus:** our own Freeverb, with three presets from the bank (`outdoor`,
  `room`, `corridor`) and a crossfade between them.
- **Reverb zones in the scene:** `ReverbZone` volumes, plus the level hint `verb`. The play scene
  gets a `room` zone over the room's inside; everywhere else is the bank's default, `outdoor`.
- **Graded occlusion:** none for a clear line; −8 dB and a 1.2 kHz low-pass for one wall; −14 dB
  and 700 Hz for two or more.
- **The schedule in the step:** `installAudio` adds `audio_schedule`, the step's last simulate
  system. It finds the listener and its zone, writes a `zone` command when the zone changes, and
  re-casts held voices' occlusion every 6 steps, at most 16 rays a step.
- **A teardown crash fixed:** a miniaudio 0.11.21 teardown bug that has been in the mixer since
  step 1 (section 3).

No render golden moved and no simulation value changed. The only expectations that moved are
`world.hash`/`schemaHash`, for the new saved type's name, plus the play scene's snapshot and entity
counts, for its new zone.

## 2. What was built

- `ohao/audio/reverb_node.{hpp,cpp}`: `Reverb`.
  - Per channel, 8 lowpass-feedback combs in parallel, then 4 allpasses in series.
  - Jezar's tunings scaled from 44.1 kHz to the engine's rate, with a stereo spread of 23 samples.
  - Denormals are flushed below 1e-25 in every feedback store, and processing runs in a fixed
    order.
  - `setPreset(preset, crossfadeFrames)` puts the new preset into the quieter of two cores (cleared
    first) and ramps the two wet gains linearly.
  - `designRt60(room)` gives the RT60 the comb feedback implies.
- `AudioSystem`:
  - The first stereo return bus runs group → `AudioReverbNode` → bus node → master. Presets cross
    threads through atomics and a version counter.
  - `setReverb(preset, frames)` and `hasReverb()`; `loadBank` starts at the bank's `defaultZone`.
  - `VoicePlacement.occlusionDb` and `occlusionLowPassHz` carry graded occlusion; Feel's on/off
    occlusion is kept for the category API.
- `ohao/audio/audio_bank`: `ReverbPreset { room, damp, wet, bed }` and `AudioBank::preset(name)`.
  The parser and bank types are now a library of their own, `ohao_audio_bank` (simdjson, no
  miniaudio), which `ohao_ecs` links.
- `ReverbZone { preset, priority, size }` (saved): registered with docs and limits, with its writer,
  `scene_tests` coverage (catalogue, random worlds) and the corpus case `23_reverb_zone`.
- The level hint `verb`:
  - It makes a `ReverbZone{preset}` on the node, and a trigger box unless the node names its own
    `col`. This is decided in `parseHints` before the scene-wide `col` default.
  - The extras schema lists it, as does the `Level` doc.
  - Fixture: `tests/level/fixtures/level_audio.gltf`, from `tests/level/make_audio_fixture.py`.
    `check_level_assets.py` validates its nodes and regenerates it byte for byte.
- `ecs/audio_schedule.{hpp,cpp}`:
  - `listenerAtStep` gives the input-driven player's head, else the first active camera.
  - `listenerZone`: the highest priority wins, then the lower id; a point on a face is inside.
  - `occlusionBetween` follows Feel's ray through characters, 4 hops, counting walls.
  - `AudioSchedule`:
    - `step()`: the zone, then the re-casts.
    - `trackVoice(source, holdMs, occlude)`: the hook step 3's play commands will use.
    - `commandsSince`, from a log of 4,096 commands.
    - `stats()`: rays cast and capped.
    - `warnings()`: `W_AUDIO_PRESET`, `W_AUDIO_BANK`.
  - `installAudio(world, assets)`, called by the CLI context and `LiveHost` after
    `installAnimation`.
- `assets/scenes/blockout_play.scene.json`: `RoomZone`, a `ReverbZone{room}` with half extents
  4 × 1.5 × 3 m at (0, 1.5, 0), added as the last entity so creation order and spawns stay. The
  level file is untouched (OPEN ruling 17).
- `audio_bench`: `reverb_10ms_ms` (gated from step 2) and `reverb_xfade_10ms_ms` (reported).
  `mix_10ms_ms` now includes the reverb.
- `audio_schedule_tests --listen DIR`: step 2's listening renders (section 5).

## 3. Bugs found and fixed

- **`audio_bench` died in teardown about one run in ten** (0xc0000005 with no output, because
  stdout was still buffered).
  - **Where:** stderr markers put the fault inside `AudioSystem::shutdown()` of the mixer that had
    played 320 periods (2 of 20 runs). The five mixers that only loaded the bank never faulted.
  - **Cause:** in miniaudio 0.11.21, `ma_node_uninit` detaches only the first node feeding each
    input. `ma_node_detach_full` reads `pNext` after `ma_node_detach_output_bus` has set it to NULL.
    - The slice's return bus is last in the bank, so it is destroyed first, while five buses still
      send to its group.
    - Four of them stayed linked into the freed `Bus`, and their own detach later wrote there.
    - The flaw dates from step 1's sends.
  - **Fix:** `destroyBuses` detaches every output (node, reverb, group) before any node goes.
  - **Verified:** 60 bench runs since, none faulted.
  - **Guard:** `t27_teardown_with_sends` (300 mixers with four senders each, in one process). It
    could not be made to fail deterministically without the fix, because in-process the freed block
    is reused and zeroed before anything reads it, so the bench loop is the red evidence.
- **The test corpus's range error path:** `E_RANGE` on a vec3 field reports the field
  (`/entities/1/ReverbZone/size`), not the component. The expected file says so.

## 4. Spec corrections

Recorded in the spec's "As built (step 2)":
- **Zones are volumes:** a zone carries its own `size`, 0 fitted to the mesh, instead of sitting
  beside a trigger `Collider`. A scene sensor would have shown in `physics.contacts`, `physics.info`
  and the serve sessions' trigger events. A level `verb` node still gets a trigger box.
- **`listenerZone` returns `std::string`**, and the listener type is `AudioListener`.
- **The reverb sits on the bank's first return bus**, starting at `defaultZone`.
- **Measured RT60s are 14–18% under the design value** (section 5).
- **`ohao_audio_bank`** is split out of the mixer.
- **The schedule has zone and occlusion commands only.** `trackVoice` is step 3's hook; snapshot
  state and ambience beds are step 3's.
- **Rays are counted per cast**, and walls are passed by ignoring the entity hit.
- **Teardown** detaches every link first (section 3).
- **A sound's `send` is not yet applied per voice:** a bus sends at one level until step 3.

**Proposed for Frank (OPEN rulings 10, 11, 12):**
- **`reverb_10ms_ms`:** keep 0.15 ms (measured 0.009, about 6% of it). A tighter gate, 0.05 ms,
  would still leave 5× headroom and catch a denormal regression, which costs about a hundredfold.
  Recommended: 0.05.
- **`mix_10ms_ms`:** keep 0.5 ms. With the reverb it measures 0.07; a tighter number waits for
  step 3's schedule driving real voices.

  room, 1.66 s may be long. If Frank hears it so in `step2_zones.wav`, `room` 0.5 gives a design

- **Occlusion** (OPEN 12): the grades as specified. Behind the pillar a shot measures 8.6 dB down,
