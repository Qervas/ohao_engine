# Sub-project 12, step 3: projected decals, tracers and the content set

**Spec:** `docs/specs/2026-10-28-vfx-design.md` ("The frame", "Data: the VFX set", "Performance budgets",
"Test plan" 33, "As built (step 3)"); plan `docs/plans/2026-10-28-vfx.md`, Task 3.
**Status:** built (step 3 of 4). A hit leaves a projected decal on the surface it hit (on the mesh box a
character's round crosses); tracers streak from the muzzle; the slice's set names generated textures. Row 12
stays open; V1–V8 wait for Frank's hand test. Nothing here is a hand-test pass.

## 1. Summary

- **Decals.** The `decals` pass projects each live decal record onto the G-buffer after `gbuffer.late`. A
  pixel is decaled only where the surface it holds lies inside the decal's box. Albedo blends by the
  texture's alpha; the normal and roughness are replaced inside its shape (the G-buffer's normal is
  octahedral and does not blend). Sky, emitters, anything nearer the eye than 0.6 m and surfaces more than
  60° off the decal's normal take nothing.
- **Placement moved.** `ecs/impact_marks` drew 64 quads; its placement now lives in `ecs/vfx.cpp` as decal
  records (the set's 256 ring, oldest dropped and counted). The quads, their mesh, material and TLAS
  instances, and the `impact_marks` system are deleted.
- **Tracers.** A `shot` with the rifle's cadence writes a tracer record. Its head runs at `speed · age`,
  clamped at the hit; its tail trails `length` behind. It is drawn additively in the forward list, sorted
  with the other transparent objects.
- **Content.** `tools/vfx/make_flipbooks.py` generates the slice's textures from fixed seeds (byte for
  byte). `assets/vfx/slice.vfx.json` is complete: the textures, the emitters' flipbooks, the decals with their
  normal maps, the tracer.

## 2. What was built

- **Decal pass:** `ohao/render/vfx/decal_pass.{hpp,cpp}` (its own render pass, pipeline, per-slot set 0 and
  instance buffer); `shaders/vfx/decal.slang` (a back-face box, no depth test, the box test on the position
  target); `DecalGpu`, `DecalPush` in `shaders/shared/layout.json`. `DecalPass::prepare` turns the frame's
  decal records into instances (the record's pose at its `on` entity's render pose, scaled by the decal's
  size and depth; the fade over the last tenth of its life). `DeferredRenderer` adds the graph pass after
  `gbuffer` and before `lights.cluster`, and keeps the pass's images on resize.
- **Frame data:** `render::VfxFrame` gains `decals`, `tracers` and the normal-map indices; `ecs/vfx_draw.cpp`
  fills them (`vfxFrameOf`; the normal maps load as linear data).
- **Placement:** `ecs/vfx.cpp` `onHit`: a hit on a character (the target or an ancestor with a
  `PlayerController`) re-casts against its mesh boxes along the same step's shot (`hitBoxes`) and attaches to
  the box crossed, or places nothing; a hit on anything else attaches to that entity; nothing on the
  input-driven player. The impact marks' helpers (`stepWorld`, `hitBoxes`) moved there unchanged.
- **Tracers:** `ohao/vfx/tracer_math.hpp` (`tracerQuad`: head, tail, six corners, centre; header-only, no
  Vulkan); `VfxRenderer::prepare` builds six `TracerVertexGpu` a visible tracer into a per-slot vertex buffer
  and adds it as object kind 2; `drawTransparent` binds the tracer pipeline (additive, the particles' depth
  test, both faces, the mask's coverage), pushes the jittered view-projection and draws six vertices.
  `shaders/vfx/tracer.slang`.
- **Content:** `tools/vfx/make_flipbooks.py` and `assets/vfx/*.png` with `assets/vfx/README.md`. The slice's
  texture paths are project-relative (`assets/vfx/...`).
- **Seams for tests:** `VfxSystem::addRecordForTest`, `DeferredRenderer::setDecalsDrawn`, the GPU suite's
  `capture` option `afterLoad`.
- **Pass registry:** `decals` (raster) after `gbuffer.late`.
- **Removed:** `ohao/ecs/impact_marks.{hpp,cpp}`; `installImpactMarks` in `runtime/live_host.cpp` and
  `tools/ohao/render_host.cpp`; the `impact_marks` simulate system in `ecs/combat.cpp`; combat_tests' five
  `fx_*` mark tests (their successors are the t33 tests below).

## 3. Bugs found and fixed

- **Textures never loaded.** The slice named `vfx/…` paths; the resolver takes project-root paths, so every
  texture failed (`E gpu: Failed to load texture: …/ohao_engine/vfx/spark.png`). Fixed in the set
  (`assets/vfx/…`); the run after the fix logs no texture errors. Before the fix the first render drew the
  sparks as hard-edged squares. That this came from the failed textures is inferred from the timing, not
  traced through the no-texture path, so it is not claimed as the cause.
- **Decals on enemy parts.** A hit on a child of an enemy (not the enemy) was decaled on that child, bypassing
  the box re-cast. `onHit` now looks up the character through the parent chain.
- **Ring dropped by a death.** The ring test's fight killed the player, and the restart cleared the ring; the
  test now gives every combatant health to spare (the ring is a cap, so a restart is a legitimate clear).
- **The GPU test's projection** ignored the camera's height, so the decal read as displaced; the test's
  screen mapping now subtracts the eye. The frame was right.
- **The GPU test's scene** named the generated set (no decals in it); the decal scenes now name the slice.
- **Pipeline order:** `DecalPass::initialize` created the pipeline before its render pass (caught by review
  of the code path, not by a test): now layouts, render pass, pipeline.

## 4. Spec corrections

"As built (step 3)" in the spec, with these as the deviations from the text: the normal test uses the
position target's finite-difference normal (the normal target is written by the pass); the normal and
roughness are replaced under the alpha threshold (OPEN ruling 16's fallback), the albedo blends; the gun is
kept clear by a 0.6 m eye clearance, not a G-buffer flag; placement re-casts in `ecs/vfx.cpp`; `t33_decal_golden`
and a separate `t33_marks_gone` are not built.

  drawn, so one on a wall a metre from the eye at the gun's position is missing rather than hidden behind it.
