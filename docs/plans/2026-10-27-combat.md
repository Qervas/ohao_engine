# Combat (Sub-project 7) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The first playable combat slice on `blockout_play.scene.json`: a hitscan rifle with fire rate, magazine, reload, recoil and seeded spread; health, damage and death; two enemies that see, chase and shoot; death and an exact restart; flash, marks, sounds and a HUD; the same fight playable by an agent over MCP.

**Architecture:**
- `installCombat(World&)` (`ohao/ecs/combat.{hpp,cpp}`) adds a `combat` simulate system after `physics`: per combatant in id order, the trigger (the World's `InputMap` for players, `WeaponTrigger` for others), cooldown, reload, bloom, recoil recovery, at most one round: an eye ray through `PhysicsScene::raycastFrom` (ignoring the shooter and triggers), damage to the nearest `Health`, events into a 1,024-entry log.
- Recoil turns the player through `PhysicsScene::turnPlayer` (the step's own write). Spread is counter-based (`hash(seed, shot, i)`), so all weapon state is in saved components and snapshots replay.
- Later tasks: enemies as characters on the player's code with an `enemy_ai` simulate system; a round-start snapshot through a host-installed `RoundHook`; presentation (light flash, quad marks, sounds, a `hud` pass); three agent methods.

**Tech Stack:** C++20, EnTT, Jolt (through `ohao/physics/backend`), miniaudio, the reflection and API layers, Python 3 harnesses.

**Spec:** `docs/specs/2026-10-27-combat-design.md`

**Interfaces:**
- Produces: `struct Health { float max, current; }`; `struct Weapon { float damage, fireRate; bool automatic; uint32_t magazine; float reloadTime, range, spreadDeg, bloomPerShotDeg, bloomMaxDeg, bloomRecoveryDegPerSec, recoilPitchDeg, recoilYawDeg, recoilRecoveryDegPerSec; uint32_t seed; std::string fire, reload; }`; `struct WeaponState { uint32_t ammo; float cooldown, reloading, bloomDeg, kickDeg; uint32_t shots; bool triggerHeld; }`; `struct WeaponTrigger { bool pull, reload; }`.
- `struct CombatEvent { enum class Kind : uint8_t { Shot, Hit, Damage, Death, Reload, Reloaded }; Kind kind; uint64_t step, seq; entt::entity source, target; uint64_t sourceId, targetId; glm::vec3 point, normal; float amount, health; std::string surface; }`.
- `CombatSystem& installCombat(World&)` (requires physics); `CombatSystem* combatSystem(World&)`; `std::span<const CombatEvent> combatEvents(const World&)`; `CombatSystem::damage(entt::entity target, float amount, entt::entity source, glm::vec3 point) -> float` (health after); `eventsSince(uint64_t, std::size_t, uint64_t& dropped)`, `nextEventSeq()`, `steps()`, `lastStepMs()`.
- `glm::vec3 combat::spreadDirection(glm::vec3 aim, float coneDeg, uint32_t seed, uint32_t shot)`; `float combat::unitRandom(uint32_t seed, uint32_t shot, uint32_t i)` in [0, 1).
- `std::optional<RayHit> PhysicsScene::raycastFrom(glm::vec3 from, glm::vec3 dir, float max, entt::entity ignore) const` (skips `ignore`'s bodies and trigger bodies); `bool PhysicsScene::turnPlayer(entt::entity, float yawDeg, float pitchDeg)`.
