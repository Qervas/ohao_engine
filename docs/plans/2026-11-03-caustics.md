# Caustics step 1 (light traced from the sun) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The offline path tracer estimates every path `sun → smooth chain → matte point seen directly → camera` by
light traced from the sun, and the camera-side tracer drops exactly those paths, so the image is the same exact
estimate with the showcase's sun-glint dots gone.

**Architecture:** OpenPBR gains a split of its BSDF into smooth and rough parts and a smooth-only sampler. Raygen keeps
`chainThroughput` and subtracts the owned terms at directional-light samples. A new raygen, `causticTrace`, in the
same pipeline, shoots rays from each directional light at caster disks, follows smooth parts, connects to the camera
through rough parts and splats into a fixed-point image that `pt.trace` adds before the running mean. It is off by
default, behind `render.capture {caustics}` and `ohao run --caustics`.

**Tech Stack:** C++20, Vulkan 1.3 ray tracing pipeline, Slang (slangc pinned), Python harnesses, CTest.

**Spec:** `docs/specs/2026-11-03-caustics-design.md` (sections "The split", "The light pass (step 1)", "Determinism",
"Test plan" c1-c7, "Rulings for Frank").

## Review Focus

1. **A coated rough base with a smooth coat** (the plinth: base 0.35, coat 0.04). The coat is in the smooth part and
   the base specular and diffuse in the rough part. The parts must sum to `eval()` exactly, and the light pass must
   connect through the base: Task 1 `t6_parts_sum`, Task 6 c2 on a coated reflector.
2. **A material exactly at the threshold** (roughness 0.25). It belongs to one side only, on both sides: Task 1
   `t6_parts_threshold`.
3. **Glass met from inside, and total internal reflection in the light pass.** Absorption and crossings as the camera
   side: Task 5 c3 (the slab's internal reflections are in its closed form).
4. **A directional light below the horizon, or a scene with no casters.** The pass is not dispatched and the image is
   bit-identical to the pass off: Task 4 `caster_none`, Task 6 c6.
5. **Splat overflow on a focused glass caustic.** `clamped` must read 0 on every test scene: Task 5 c3 asserts it.

### Task 1: OpenPBR's smooth/rough split and smooth-only sampler

**Files:**
- Modify: `shaders/material/openpbr.slang` (`OpenPBRBase`, `OpenPBRSurface`)
- Modify: `tools/material/openpbr_kernel.slang`, `tools/material/openpbr_cpu.hpp` (new ops)
- Test: `tests/material/material_tests.cpp` (`t6_*`)

**Interfaces:**
- Produces, on `OpenPBRSurface` (and `OpenPBRBase` beneath it):
  - `void evalParts(float3 wo, float3 wi, OpenPBRTables t, float cut, out float3 smooth, out float3 rough)`: the
    smooth part holds the base's specular and transmission lobes when the base's roughness `< cut`, and the coat's lobe
    when the coat's roughness `< cut`; the rough part holds everything else `eval()` holds. `smooth + rough == eval(wo,
    wi)` in every case; the walked subsurface is in neither, as `eval()` already leaves it out.
  - `bool hasSmooth(float cut)`: any lobe with weight > 0 below `cut`.
  - `BsdfSample sampleSmooth(float3 wo, float3 u, OpenPBRTables t, float cut)`: a draw from the smooth lobes only (a
    lobe chosen in proportion to its albedo at wo), `s.weight = smooth(wo, s.wi) / s.pdf`, `s.lobe` as `sample()` sets it.
  - `float pdfSmooth(float3 wo, float3 wi, OpenPBRTables t, float cut)`: its density.
- Produces, in the CPU twin: `Op::Parts = 14` (r0 = smooth, r1 = rough), `Op::SampleSmooth = 15`,
  `Op::PdfSmooth = 16`, with `cut` in `Item::v`'s unused slot or a new `Item::cut` field (implementer's choice; one
  place).
