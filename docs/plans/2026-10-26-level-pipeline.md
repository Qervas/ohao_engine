# Level Pipeline (Sub-project 5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A level exported from Blender (glTF 2.0 with node `extras`) loads into the world as one entity per node, renders through the GPU-driven `RenderScene`, builds Jolt collision from its hints, and is readable by agents (`level.info`, `physics.raycast`, spawn points), as one `Level{asset}` line in a scene file.

**Architecture:**
- `ohao/level` reads a glTF file's structure (nodes, `extras`, `KHR_lights_punctual`, cameras) from its JSON. Geometry and materials come from the existing Assimp `ModelLoader`, one glTF mesh at a time.
- A `level` sync system (before `instantiate`) expands a `Level` component into child entities with deterministic ids that are never saved. Mesh nodes reference `ModelAsset{asset, mesh}`, so instantiate's cache shares one GPU mesh per glTF mesh.
- A `physics` sync system (after `transform`) builds `PhysicsBackend` (Jolt) bodies from `Collider` and `RigidBody`. It does not step them; that is sub-project 6.
- `ohao/api` adds `level.*` and `physics.*` methods; the CLI adds `ohao level`.

**Tech Stack:** C++20, EnTT, Assimp (existing), Jolt (existing, through `ohao/physics/backend`), `ohao_reflect`'s JSON values, Blender 5.2.2 headless for tools only, Python 3 harnesses.

**Spec:** `docs/specs/2026-10-26-level-pipeline-design.md`

## Review Focus

1. A scene saved after a level loaded writes only the `Level` entity, never its node entities. Reloading such a scene must not double the level (Task 3, `t04_save_writes_only_the_level`).
2. A misspelt hint (`"coll":"box"`, `"Lihgt":{…}`) never silently changes a level: lower-case unknown keys warn, capitalised ones fail, both naming the node path (Task 3, `t02_extras_errors_name_the_node`).
3. `level.reload` of an unchanged file keeps `world.hash`, and level node ids are equal across processes (Task 3, `t04_reload_keeps_world_hash`, `t04_ids_stable_across_processes`).
4. A mirrored node (negative-determinant transform) gets a collider with outward normals, and the ray tests see its faces (Task 4, `t06_mirrored_node_collides_outward`).
5. A `vis: 0` node costs no `MeshRenderer`, no upload and no BLAS (Task 3, `t04_collision_only_nodes_have_no_renderer`).
