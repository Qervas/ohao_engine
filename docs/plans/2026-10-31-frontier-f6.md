# Frontier F6: Slang everywhere

**Spec:** `docs/specs/2026-10-30-frontier-renderer-design.md`, section 3 (step F6): the G-buffer, TAA, bloom, the gizmo
and the remaining compute in Slang. Retires every GLSL stage and `layout.glsl`.
**Status:** done (2026-10-31): `docs/changes/2026-10-31-frontier-f6.md`.

## Before F6

Thirteen GLSL files were left, every other shader Slang: the G-buffer (`core/gbuffer.vert`, `gbuffer.frag`,
`gbuffer_mask.frag`, `includes/scene/gbuffer_body.glsl`, `scene_data.glsl`), the post stack's fullscreen triangle, bloom's
downsample and upsample and TAA's resolve, the CSM vertex shader, the gizmo, and the generated `shared/layout.glsl`.
`cull/meshlets.slang` repeated `gbuffer.vert`'s arithmetic by hand so the meshlet path's images equal the instance
path's. `glslc` was a build and `ohao doctor` requirement.

## Steps

Each a line-for-line translation, expressions in the same order, every realtime deferred golden exact after it.

- **F6a, the post stack.** `postprocess/fullscreen.slang`, `bloom_downsample.slang`, `bloom_upsample.slang`,
  `taa_resolve.slang` (`SV_VulkanVertexID`: gl_VertexIndex).
- **F6b, CSM and the gizmo.** `shadow/shadow_csm.slang` (`SV_VulkanInstanceID`: firstInstance is the draw), the
  matrices multiplied first as GLSL's `viewProj * world * p` did; `overlay/gizmo.slang` (two entries).
  `includes/scene/scene_data.slang`: the instance table's struct.
- **F6c, the G-buffer.** `core/gbuffer.slang` (`vertexMain`, `opaque` with early depth tests, `masked` with the discard);
  `includes/scene/gbuffer_vertex.slang`: the vertex transform, one function both the instance path and the meshlet path
  (`cull/meshlets.slang`) call, so their images are equal by construction.
- **F6d, GLSL retired.** `tools/gen_layout.py` writes `layout.slang` and the C++ header only; `shaders/CMakeLists.txt`
  has no glslc rule; `ohao doctor` drops `tools.glslc` and GLSL's `#include` following; `check_layout` and
  `check_doctor`'s fake trees are Slang.
