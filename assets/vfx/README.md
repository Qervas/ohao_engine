# assets/vfx

The VFX slice's set (`slice.vfx.json`, named by `blockout_play.scene.json`'s `VfxSet`) and the textures
it names. Ours, MIT: the PNGs are generated by `tools/vfx/make_flipbooks.py` from fixed seeds, and no
file here came from an upstream pack, so there is no `LICENSE.md` or `README.upstream.md`.

| File | What | Used by |
|---|---|---|
| `smoke_8x8.png` | 8x8 flipbook of 64 px soft puffs, alpha = density (fbm-broken disc, a seed per cell) | `smoke` (alpha emitters, `frames: life`) |
| `flash_4x1.png` | 4x1 flipbook of 64 px muzzle stars, opening, peaking, fading | `flash` (muzzle, `frames: random`) |
| `spark.png` | 64 px hot dot with a short streak, additive | `spark` (sparks, the grenade's debris) |
| `decal_bullet.png` | 64 px bullet hole: soft dark ring, alpha = hole (the set tints it) | `bullet` decals, albedo and alpha |
| `decal_bullet_n.png` | the hole's normal map (linear RGB, a shallow crater) | `bullet` decals, normal (never sRGB) |
| `decal_scorch.png` | 128 px burn mark, uneven, soft edge | `scorch` (the grenade's decal) |

Rebuild (byte for byte, twice in a row gives the same files):

```
python tools/vfx/make_flipbooks.py          # writes assets/vfx/*.png
python tools/vfx/make_flipbooks.py --check  # regenerates to a temp dir and compares
```
