# assets/levels: checked-in levels

Levels for the level pipeline (`docs/specs/2026-10-26-level-pipeline-design.md`):
glTF 2.0 binaries exported from Blender, whose node `extras` carry the level hints (`col`,
`body`, `mass`, `vis`, `spawn`, `socket`). `.gitattributes` keeps every file here byte for
byte.

| File | What it is | Made by | License |
|---|---|---|---|
| `blockout_room.glb` | an 8 × 6 m room open to the sky: floor, walls with a doorway and lintel, a 0.3 m step, a 0.6 m platform, a ramp, a pillar, two dynamic crates, three spawn points (`player`, 2 × `enemy`) and a camera | `tools/level/blockout_room.py`, Blender 5.2.2 | MIT, as the repository: the geometry and materials are generated by the script |

Rebuild (byte for byte with Blender 5.2.2; `tests/level/check_level_assets.py` checks it):

```
C:/Users/djmax/scoop/shims/blender.exe -b --factory-startup --python tools/level/blockout_room.py -- assets/levels/blockout_room.glb
```

Scenes that use it: `assets/scenes/blockout_room.scene.json` (golden
`cli_blockout_room_deferred`). Staged assets that may not be published go to
`assets/local/`, never here.
